# Expense Tracker

A modern and responsive expense tracking application built with React. This project helps users manage their income, expenses, and monthly budgets while providing clear insights into their spending habits through interactive reports and visualizations.

The project was built to strengthen my understanding of React by focusing on state management, reusable components, and clean project architecture.

---

## Features

- Dashboard with financial overview and key statistics
- Add, edit, and delete income & expense transactions
- Budget management with spending progress
- Monthly reports and spending insights
- Category-wise expense breakdown
- Search, filter, sort, and paginate transactions
- Data backup and restore (Export/Import JSON)
- Fully responsive user interface
- Persistent data using Local Storage

---

## Project Structure

```
src/
├── components/

├── reducers/
├── hooks/
├── utils/
├── pages/
├── routes/
└── data/
```

The project follows a modular structure where UI components, business logic, hooks, reducers, and utility functions are kept separate to improve readability and maintainability.

## Getting Started

Clone the repository

```bash
git clone https://github.com/Arman2602/expense-tracker.git
```

Navigate to the project

```bash
cd expense-tracker
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
